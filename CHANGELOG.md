# Changelog

All notable changes to MBS Cloud Kitchen are documented here.

## v1.0.0 — Production Launch

- Production deployment checklist and monitoring runbook
- Security headers with nonce-based CSP
- Rate limiting on login, orders, catering, and webhooks
- Vitest unit tests and Playwright E2E suite
- Accessibility audit via axe-core

## v0.8.0 — Phase 8: Observability, SEO & Security

- Sentry error monitoring (client, server, edge)
- Vercel Analytics and Speed Insights
- Dynamic sitemap, robots.txt, JSON-LD structured data
- Dynamic OG images and PWA manifest
- Bundle analyzer, Lighthouse CI
- Security headers, CSP, automated tests (Phase 8B)

## v0.7.0 — Phase 7: AI Chatbot

- pgvector RAG knowledge base
- `/api/chat` streaming endpoint with rate limiting
- Chat widget with suggested questions
- Admin knowledge viewer and auto menu re-index

## v0.6.0 — Phase 6: Cart, Checkout & WhatsApp

- Shopping cart with Zustand persistence
- Checkout flow with order confirmation
- WhatsApp deeplink and Cloud API foundation
- Admin orders and catering request dashboards

## v0.5.0 — Phase 5: Admin CRUD

- Admin menu and catering item management
- Supabase Storage image uploads
- Featured dishes and availability toggles

## v0.4.0 — Phase 4: Database & Auth

- Prisma + Supabase PostgreSQL
- Auth.js v5 admin authentication
- Admin shell and query helpers

## v0.3.0 — Phase 3: Menu & Catering Pages

- Full menu with filters and search
- Multi-step catering enquiry form
- Catering menu preview

## v0.2.0 — Phase 2: Content Pages

- About page with MDX content
- Contact page with inquiry form
- SEO metadata helpers

## v0.1.0 — Phase 1: Foundation

- Next.js 14 App Router setup
- Brand theme, home page, hero section
- Header, footer, and navigation
